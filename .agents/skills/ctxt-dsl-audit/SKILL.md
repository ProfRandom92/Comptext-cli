---
name: ctxt-dsl-audit
description: Validate and evolve the CompText DSL grammar, skill syntax, resource syntax, tool blocks, task blocks, and examples.
---

Use this skill when working with CompText DSL syntax or grammar.

Rules:
- `$skill-name` is supported.
- `@resource/path` is supported.
- `tool {}` is a DSL representation for MCP-compatible tool descriptions.
- `task {}` is a CompText DSL abstraction, not an official MCP primitive.
- Examples must be parseable and tested.
